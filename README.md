# 成實論 · Chengshilun · Сатьясиддхи-шастра

Полный русский перевод буддийского философского трактата
**«Сатьясиддхи-шастра»** (санскр. *Satyasiddhi-śāstra*).

- Китайское название: **成實論** (Chéngshílùn)
- Автор: **Хариварман** (Harivarman)
- Китайский перевод: **Кумараджива**
- Канон Тайсё: **T1646**
- Язык перевода: русский

---

## О трактате

«Сатьясиддхи-шастра» — один из наиболее значительных буддийских трактатов IV века,
оказавший большое влияние на развитие китайского буддизма.

Вокруг этого произведения возникла самостоятельная школа
**Чэнши-цзун (成實宗)**.

Трактат занимает промежуточное положение между ранней Абхидхармой
и философией Махаяны.
